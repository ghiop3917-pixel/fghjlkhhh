# Краткое состояние для продолжения

Рабочая папка: AI Cartoon Studio, новый Python-проект. Перед продолжением достаточно README, этого файла и нужных модулей; весь архив переписки читать не нужно.

- Запуск: `python -m studio doctor|api|production|bot|worker|backup`.
- Безопасные настройки: `.env.example`; создан локальный `.env` с двумя случайными токенами. Не выводить его содержимое. STUDIO_SERVER_ENABLED=false сохраняет правило «Lenovo только рендер».
- Ядро: studio/db.py; SQLite WAL, leases/fencing, идемпотентная очередь, версии объектов, архив ровно из трёх полей.
- API/Mini App: studio/api.py и studio/static/. У владельца отдельный bearer или подписанный Telegram initData; у Worker другой bearer.
- Производство: studio/production.py, media.py; сценарий → согласование → Piper/2D/музыка/ASS → render → QC → семь человеческих проверок. Редакции выборочно переиспользуют проверенные изображения/WAV/музыку по отдельным ключам входных данных и SHA-256; оригиналы не изменяются, субтитры пересчитываются. Финальный рендер остаётся полным.
- Router: Cloudflare Free, Gemini Free с ручной проверкой аккаунта, серверный Ollama; по умолчанию отключены. Никаких фиктивных ответов.
- Правки обычным текстом: conversation.py; конкретное предложение, before/new, подтверждение владельца, транзакционное применение и конфликты версий.
- Bot: bot.py; один владелец, private chat, команды, темы, предложения правок, уведомления, режим и расписание.
- Worker: worker.py; Windows-only, HTTPS, проверка SHA-256, FFmpeg, heartbeat. Реальный NVENC здесь не работает с драйвером: auto корректно выбирает libx264.
- Публикация: publishing.py; только согласованная private-загрузка YouTube, резервирование до запроса, readback, запрет повторов при неоднозначности. TikTok — ручной файл.
- Аналитика: analytics.py, platform_analytics.py; ручной импорт и условное OAuth-чтение YouTube, сводки комментариев без хранения исходников.
- VPS: compose.yaml, deploy/Dockerfile, Caddyfile; сборка и развёртывание ещё не проводились. В образ включена установка Piper, но голос нужно выбрать и предоставить отдельно.
- 2D-внешность: studio/character_art.py, версия 2d-v2. Необязательный render_style в паспорте: haircut/build/outfit/face_shape/skin_color/glasses/earrings/necklace; старые паспорта работают через простые текстовые признаки. Старый рисователь сохранён как legacy_character_frame. В панели есть предпросмотр с эмоциями; API /api/characters/ID/preview возвращает PNG из памяти только владельцу.
- Учебные истории о ЧС: studio/emergencies.py, format=emergency_story, темы nuclear/suspicious_object/armed_attack. Отдельная память critical_situations. Выбор темы в панели и /emergency в боте. Перед подготовкой обязательна проверка владельцем, привязанная к хешам сценария и реестра источников. Изменения требуют нового согласования. Встроенная маркировка вымысла, ссылки в метаданных и проверка описания YouTube. Три импортируемых примера в examples/critical_situations; инструкция и первичные источники в docs/КРИТИЧЕСКИЕ_СИТУАЦИИ.md.
- Фактические проверки и незавершённые функции: reports/ПРОВЕРКИ.md. 61 обычный тест прошёл; длительные рендеры включаются отдельно. Ранее прошёл 30-секундный MP4; дополнительно проверен реальный 32-секундный MP4 учебной истории с проверкой маркировки в извлечённом кадре. Ruff и compileall проходят. Браузерная проверка персонажей, эмоций, формата ЧС и согласования советов — PASS. Реальные внешние интеграции не проверены.
- Физическое удаление отключено. Не выдавать проект за полностью готовую автономную студию по всему исходному ТЗ.
