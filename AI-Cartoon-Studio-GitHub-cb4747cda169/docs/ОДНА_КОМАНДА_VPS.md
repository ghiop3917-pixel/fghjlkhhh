# Загрузить ZIP и начать работу

## Что потребуется один раз

Чистый Ubuntu 24.04 VPS, Python 3 (обычно уже установлен), права sudo, домен с DNS на VPS и открытые порты 80/443. Нужны токен вашего Telegram-бота, ваш числовой Telegram ID, Account ID и API Token бесплатного Cloudflare Workers AI без платёжного подключения. Покупки, регистрация аккаунтов и выдача разрешений не выполняются программой.

## Действия на VPS

Загрузите новый исходный ZIP в домашнюю папку сервера через панель хостинга или SFTP. Распаковывать вручную не требуется. В SSH выполните, подставив имя загруженного архива:

```bash
sudo python3 AI-Cartoon-Studio-VPS-ИМЯ.zip
```

Мастер один раз запросит домен и доступы; секреты вводятся скрыто. Далее автоматически:

1. Проверит файлы ZIP и создаст отдельную папку в `/opt`.
2. При отсутствии Docker установит Engine и Compose из официального репозитория Docker. Существующие контейнерные пакеты не удаляются; при конфликте установка остановится с объяснением.
3. Создаст настройки и отдельные ключи владельца и Lenovo.
4. Соберёт образ, проверит конфигурацию, создаст пробную русскую речь и изображение. Финальный MP4 на VPS не создаётся.
5. Запустит сервисы с восстановлением после перезагрузки, проверит HTTPS и поставит первую подборку идей в очередь.
6. Напечатает имя секретного `LENOVO-....zip`, уже настроенного на этот сервер.

Установка Docker основана на [официальной инструкции](https://docs.docker.com/engine/install/ubuntu/). Установщик не меняет правила firewall и не останавливает чужие сервисы. При занятом порте, неправильном DNS или конфликте пакетов потребуется исправить конкретную причину.

## Один раз на Lenovo

Скачайте созданный сервером `LENOVO-....zip` по SFTP из напечатанной папки `/opt/cartoon-studio-...`. Это секретный архив с ограниченным ключом рендера; не пересылайте его посторонним. Ключи Telegram, ИИ и владельца панели в него не входят.

Распакуйте в новую отдельную папку на подготовленном Lenovo и откройте `ЗАПУСТИТЬ.cmd`. Существующая папка проекта не заменяется. Запуск создаст отдельное окружение, установит недостающие библиотеки и подключит Worker. Python 3.12+ и FFmpeg должны быть доступны; на текущем Lenovo они уже проверялись. Держите окно открытым или свёрнутым во время работы.

Откройте вашего бота, нажмите «Запустить», затем отправьте `/app`. Студия предложит идеи; выберите сюжет и согласуйте сценарий. Для настоящего диалога с ботом пользователь должен начать чат сам — программа этого сделать не может.

Перед выдачей готового пакета на рендер бот автоматически предупредит владельца за 10 минут. Отсчёт начинается после подтверждённой отправки Telegram; без доставки рендер ожидает. Сообщение содержит название серии и просьбу оставить Lenovo включённым. Предупреждение привязано к задаче, сохраняется при перезапуске и не повторяется при обычном опросе очереди. Если ПК отключится, старт задержится. Это уведомление о готовом рендере, а не обещание ежедневно создавать видео без согласованного сценария. Настройка `STUDIO_RENDER_WARNING=true` включена по умолчанию; ключ Telegram остаётся только на сервере.

## Что не требует ручного написания настроек

Не нужно редактировать `.env`, создавать токены студии, устанавливать Docker вручную на чистом Ubuntu, запускать сервисы по отдельности, выбирать исходные три темы или вводить адрес VPS на Lenovo. Новые темы ИИ придумывает самостоятельно.

## Границы готовности

Резервная озвучка eSpeak работает без скачивания отдельного голоса, но звучит роботизированно. Естественный голос Piper требует выбранной лицензированной модели. Облачный доступ зависит от региона и условий аккаунта. YouTube/TikTok требуют отдельных OAuth-разрешений; без них доступен файл для ручной публикации. Выбор сюжетов, просмотр и отправка видео требуют решения владельца.

Настоящий Linux-запуск и внешние аккаунты пока не проверены: этот компьютер не содержит Docker и доступов к VPS. Локальные тесты проверяют порядок действий, сохранность настроек, разделение ключей и ошибки установщика, а не заменяют проверку сервера.
