# Архитектура и технические ограничения

Дата исследования: 12 ноября 2026. Статус: реализован локально проверяемый базовый конвейер; внешняя эксплуатация не подтверждена.

## Обследованная среда

Рабочая папка изначально пуста. Обнаружены Python 3.12.10, Git, Node, Ollama, FFmpeg 9.0.2 и ffprobe. CPU: Intel Core i5-13450HX. GPU: RTX 4050 Laptop, 6141 MiB; драйвер 581.86. Полная память системы и версия ОС через CIM недоступны в песочнице: заявленные 16 ГБ и Windows 11 независимо не подтверждены. VPS отсутствует.

NVENC фактически проверен коротким тестом: ошибка несовместимости API (требуется 13.1, драйвер предоставляет 13.0). Текущая сборка FFmpeg сообщает необходимость драйвера 610.00+. Драйвер и FFmpeg не менялись. Worker проверяет NVENC перед задачей и выбирает libx264 при отказе. Производительность не обещается до замера полного ролика.

## Разделение ответственности

VPS: FastAPI, Telegram polling, статическая Mini App, SQLite WAL, планировщик, роли агентов, маршрутизатор моделей, RSS, сценарии, паспорта, Pillow 2D, Piper WAV, ASS, монтажные пакеты, технический QC через полное декодирование, архив, аналитика, согласованная приватная загрузка YouTube. Сервер не создаёт финальные MP4.

Lenovo: исходящее HTTPS-соединение с VPS, скачивание материалов по SHA-256, FFmpeg-сборка и отправка MP4. Входящие порты на ПК не нужны. Рабочие серверные процессы на Lenovo отключены по умолчанию; локальные проверки разрешаются только как тесты. В тестах нет реальных внешних AI-запросов.

Роли — инструкции и разделение ответственности общего Router, а не 12 одновременно запущенных моделей. На сервере один последовательный производственный потребитель. Redis, Celery, Kubernetes и отдельная векторная БД на старте не нужны. SQLite работает на локальном диске VPS; не размещать живую БД на NFS/OneDrive.

## Состояния и восстановление

Тема → согласование темы → сценарий → редактор → согласование сценария → изображения/WAV/ASS → пакет → очередь render → Worker → технический QC → семь проверок владельца → архив и сюжетная память → отдельное согласие на отправку MP4.

Очередь: уникальный dedupe, BEGIN IMMEDIATE для захвата, lease 120 секунд, heartbeat 25 секунд, уникальный fencing token каждой аренды. После обрыва задача восстанавливается; устаревший результат отклоняется. Максимум 3 попытки исполнения. Ненастроенный поставщик переводит задачу в ожидание без расхода попыток. Повтор начинается с сохранённого пакета; продолжение FFmpeg с точного кадра не реализовано. Просроченные аренды восстанавливаются при следующем claim.

AUTO/PC: рендер только при обращении Worker. VPS: рендер удерживается в очереди, подготовка продолжается. Изменение режима не прерывает уже арендованный рендер. На VPS нет резервного рендера, что соответствует прямому запрету в задании.

Сценарная правка создаёт новую редакцию серии, старая сохраняется. Подготовка находит пакет предыдущей подготовленной редакции (до 20 переходов с защитой от циклов). Изображения и озвучка имеют отдельные ключи входных данных: визуальные параметры отделены от реплики и голоса. Ключ аудио учитывает содержимое модели, конфигурации, версию Piper и исполняемый файл. Переиспользование требует совпадения ключа, размера и SHA-256; файлы копируются без hardlink и без изменения оригиналов. Повреждённые/отсутствующие материалы создаются заново. Музыка переиспользуется при том же генераторе и длительности. Субтитры, тайминг, метаданные и обложка пересобираются. Старые пакеты без ключей входных данных совместимы, но не переиспользуются. Финальный рендер новой редакции пока выполняется целиком. Неизменяемый пакет фиксирует хеш паспорта каждой сцены. Изменение паспорта не меняет уже готовый пакет.

История объектов сохраняется с откатом в новую версию. Архив имеет строго три колонки: season_title, episode_title, full_script. Память персонажей, конфликтов, аналитики, переписка и события находятся отдельно. В модель передаётся рабочая память, не архив всех сценариев; общий контекст ограничен 24000 символами. Архив адресно доступен через SQL; отдельный интерфейс чтения старой серии пока не создан.

## Модели и бесплатность

Проверены официальные документы, но не доступ конкретного аккаунта. Наличие бесплатного тарифа не является гарантией квоты, доступности из РФ или качества. Никакие облачные запросы разработки не выполнялись.

| Вариант | Назначение | Ограничение и решение |
|---|---|---|
| Cloudflare Workers AI | Базовая облачная текстовая модель | 10000 neurons/сутки на Free; после исчерпания отказ. Часть моделей требует оплаты. После сверки каталога 13 ноября стартовый маршрут обновлён на @cf/qwen/qwen3.8-27b; reasoning_effort=low, лимит ответа 2400, поддержан choices-ответ. Доступ и тариф конкретного аккаунта проверяются при подключении. Локальный счётчик запросов — дополнительный предел, не точный счётчик neurons. Только отдельный Free-аккаунт без оплаты. |
| Gemini API | Дополнительный текстовый провайдер | Бесплатны только отдельные модели/функции; точный ID и квота проверяются в аккаунте. В опубликованном списке поддерживаемых регионов РФ отсутствует. Не использовать обход ограничений. На Free данные могут использоваться для улучшения продуктов. По умолчанию отключён. |
| Hugging Face Inference Providers | Возможный будущий провайдер изображений | Есть небольшие ежемесячные кредиты, затем возможна оплата. Не выбран как надёжная бесплатная основа и не подключён в коде. |
| Qwen3 0.6B через Ollama | Резерв для простых текстовых задач | Малый вариант, но RAM включает runtime и KV-cache. На VPS 2 ГБ только после замера в изоляции; качество сценариев не гарантируется. Ollama адаптер готов, модель не скачивалась. |
| Qwen3 1.7B | Более сильный локальный кандидат | Размер весов и runtime оставляют недостаточный запас для общей системы на 2 ГБ. Не рекомендуем по умолчанию. |
| Piper | Русская CPU-озвучка на VPS | Нужны установка движка, конкретная модель голоса и проверка её лицензии. Актуальный движок GPL-3.0; лицензии голосов отдельные. Реальный голос в проект не включён. |
| Pillow + постоянный 2D-риг | Визуальный резерв без GPU | Фронтальный персонаж, три эмоции, городские декорации, движение камеры. Не полноценная нейросетевая анимация и не произвольная одежда по тексту. |

Router последовательно пробует разрешённые облака и локальный серверный Ollama. Рейтинг качества по реальным замерам, автоматическое обнаружение тарифов и динамическая оптимизация моделей пока не реализованы. При неизвестном тарифе поставщика подключать нельзя. Булевое подтверждение Free в .env — операторское подтверждение, а не программная проверка billing. Жёсткий нулевой расход обеспечивается отсутствием платёжного подключения, а не только нашим счётчиком. При отсутствии всех провайдеров задача ждёт, ответ не имитируется.

## Тренды, медиа и контроль

Стартовый сборщик: разрешённые оператором HTTPS RSS, максимум 12 источников, 40 элементов/источник, возраст до 72 часов, обязательная дата, точный dedupe нормализованного заголовка. Рейтинг — свежесть, не измеренная вирусность. Нет обещания семантической дедупликации или автоматического фактчекинга. TikTok, X, Reddit, Telegram-каналы и YouTube как источники трендов пока не подключены: нужны отдельные разрешённые способы доступа и квоты.

Паспорта хранят все поля задания. Рисователь 2d-v2 в character_art.py поддерживает четыре причёски, три телосложения, три вида одежды, три формы лица, тон кожи, очки, серьги и цепочку. Точный набор параметров задаётся необязательным render_style; без него поддерживаются простые ключевые слова старых паспортов. Прочие описательные детали не гарантируются. API предпросмотра доступен только владельцу, создаёт PNG в памяти без временных файлов; в Mini App есть выбор трёх эмоций. Версия рисователя включена в ключ изображения: старые PNG не подставляются вместо новой графики. Исходный legacy_character_frame сохранён для совместимости. Для референсной нейрогенерации и автоматического сравнения внешности нужен отдельный визуальный провайдер. Пока внешность проверяет владелец, хеш фиксирует версию паспорта. Это не нейросетевая проверка сходства.

Piper — единственный реализованный TTS-адаптер. Тишина и синус используются только в тестах, никогда вместо речи production. Длительность проверяется по WAV; если вне 30–60 секунд, задача останавливается после ограниченных повторов. Автоматическое переписывание сценария по длительности ещё не реализовано. ASS использует оценочные интервалы слов; точное forced alignment не реализовано. Нужна проверка на слух и просмотр.

QC: ffprobe, 1080×1920, H.264 yuv420p, AAC, длительность, расхождение длительностей дорожек, полное декодирование. Читаемость, естественность голоса, смысл, соответствие персонажей и фактов подтверждаются семью отдельными галочками владельца, а не поддельным автоматическим PASS. Редактор передаёт найденные дефекты следующей попытке сценариста; автоматическая коррекция всех творческих дефектов не реализована. Есть собственный простой синтезированный музыкальный фон ambient: WAV создаётся на сервере, тихо смешивается Worker; music=none отключает его. Сторонних музыкальных записей нет.

## Публикация и аналитика

YouTube: OAuth refresh-token, resumable upload, приватность private, повторное чтение статуса. Перед отправкой нужны семь проверок, совпадающий SHA-256 и явное подтверждение точных метаданных. Начатая публикация резервируется до внешнего запроса. При неоднозначном ответе повтор блокируется до ручной сверки. Публичность, расписание, thumbnail API и автоматическое восстановление сессии загрузки пока не реализованы.

TikTok Direct Post требует соответствия аудиту и пользовательскому UX. Официальные правила прямо исключают внутренние утилиты для загрузки только на свои аккаунты. Поэтому обещать публичный автопостинг этой частной студии нельзя; готовый MP4 доступен для ручной загрузки. Текущий MVP не обращается к TikTok API.

Метрики импортируются владельцем через API/панель; исходные значения неизвестных метрик — null. Дополнительно реализован OAuth-адаптер YouTube: просмотры, доступное среднее удержание, подписки и до 100 верхнеуровневых комментариев. Он запускается перед следующим сценарием при YOUTUBE_ANALYTICS_ENABLED=true и известном video_id предыдущей серии; реальный доступ требует проверки аккаунта. Сводка комментариев создаётся без записи исходников в БД и журналы. Внешние запросы сводки требуют отдельного включения облаков; тексты уходят разрешённому поставщику. Еженедельный отчёт ставится в очередь по понедельникам UTC. TikTok Analytics не реализован. Популярность персонажей и поворотов хранится как редакционные заметки, не как автоматически измеренная причинность.

## Безопасность и хранение

Разные токены API/Worker, Telegram ID и подпись initData с проверкой срока 15 минут, HTTPS VPS, без входящих портов на ПК. Секреты в .env, не в UI. Прямые действия выполняются валидированными командами, ИИ не имеет произвольного shell/API. Подсказки из комментариев — недоверенные данные; модельная защита сама по себе не абсолютна, поэтому у модели нет инструментов.

Ограничены размеры RSS, запросов proxy, пакета и MP4; пути проверяются на traversal, файлы на SHA-256. В качестве источников настраивать только доверенные домены: DNS rebinding не полностью устраняется предварительной DNS-проверкой; произвольные URL от модели не разрешать. Сервис запускать под непривилегированным пользователем, только один bot polling и один production.

Удаление физически не реализовано и не запускается. Есть только план кандидатов. Перед будущей очисткой нужно отдельное согласование, проверка публичной публикации и резервная копия важных файлов вместе с базой. backup использует SQLite backup API; это копия только БД, не каталогов. Эталоны, голоса и готовые MP4 копируются отдельно. На VPS контролировать диск: материалы сохраняются до отдельного решения владельца.

## Следующие контрольные точки

1. Локальные тесты очереди, auth, пакета, FFmpeg и QC.
2. На VPS проверить реальные 2 vCPU/2 ГБ, свободный диск, сеть, DNS и права файлов.
3. Настроить Piper/голос, прогнать русскую озвучку и замер RAM. При необходимости включить только одну небольшую LLM, не параллельно TTS.
4. Выдать один разрешённый бесплатный облачный ключ и проверить модель, регион, тариф, лимиты, отказ при исчерпании.
5. Telegram private chat, Mini App HTTPS, heartbeat настоящего Lenovo, отключение и повторное включение.
6. Просмотр/прослушивание полноценной русской серии; сверка сохранения памяти следующей серии.
7. OAuth YouTube и отдельное согласование тестовой приватной загрузки. Только затем решать публичную эксплуатацию.

Бюджет VPS до 400 ₽ не является бесплатным стартом. Здесь нет аренды и платных операций; наличие подходящего тарифа VPS не проверялось. При отсутствии сервера можно подготовить код и провести локальные тесты, но круглосуточная автономная эксплуатация без вычислительной площадки невозможна.
