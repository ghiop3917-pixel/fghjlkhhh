# Управление студией в Telegram

Доступно только владельцу в личном чате. Сначала нажмите «Запустить» у бота.

## Перед рендером

Предупреждение за 10 минут содержит кнопки «Я готов — запускай», «Через 30 минут», «Через час», «До вечера». Последняя переносит на ближайшие 18:00 по времени студии, завтра, если 18:00 уже прошло. После переноса снова приходит предупреждение. Запущенная задача не прерывается; устаревшая кнопка отклоняется. При выключенном или занятом Lenovo старт задерживается.

## Прогресс и просмотр

Бот сообщает о подготовке материалов. Lenovo передаёт реальные этапы: загрузка пакета, сцена N из M, итоговая сборка, отправка результата. Одно сообщение прогресса обновляется, без выдуманного процента и прогнозов времени.

После успешных проверок ролик приходит в Telegram с кнопками «Одобрить» и «Исправить». Для файлов больше 49 МБ предлагается просмотр в /app: [облачный Bot API ограничивает видео 50 МБ](https://core.telegram.org/bots/api#sendvideo). Сервер видео не пережимает и не рендерит.

Одобрение требует семи отдельных отметок после просмотра: сценарий, персонажи, звук, изображение, субтитры, достоверность, итоговое решение. Согласование привязано к хешу текущего MP4. Публикация этим не разрешается.

«Исправить» предлагает следующим сообщением написать замечания. Будет создана отдельная редакция с повторным согласованием сценария. Исходные материалы остаются; автоматических исправлений максимум три. /cancel отменяет ожидание замечаний.

## Тихие часы

По умолчанию 23:00–09:00, Москва UTC+3: новые рендеры и обычные уведомления ждут утра. Уже начатая сборка заканчивается. Утром ожидающий рендер получает новое предупреждение.

```text
/quiet 23 9 3
/quiet 22 8 3
/quiet off
```

Смещение UTC постоянное, от −12 до +14; летнее время автоматически не учитывается. На явные команды владельца бот отвечает и ночью.

## Сводка

Ежедневно в 19:00 местного времени: идеи на выбор, серии на согласование, готовые видео, очередь и состояние Lenovo. Одна сводка за текущую дату, без рассылки пропущенной истории. Тихие часы имеют приоритет.

```text
/summary
/summary 18
```

Первая команда показывает сводку сразу, вторая меняет ежедневный час.

## Проверка Lenovo

Worker передаёт свободное место и наличие FFmpeg. Перед выдачей рендера проверяются связь не старше 90 секунд и минимум 2 ГБ свободного места. При проблеме приходит предупреждение, удаления файлов нет. Порог: STUDIO_WORKER_MIN_FREE_GB на сервере.

Обновите сервер и комплект Lenovo: старый Worker не передаёт данные диска и прогресс. Реальные сообщения требуют подключения Telegram; локальные тесты имитируют ответы API.
