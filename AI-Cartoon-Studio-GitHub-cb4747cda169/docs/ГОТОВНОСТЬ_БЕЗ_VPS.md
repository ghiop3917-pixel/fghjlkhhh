# Состояние комплекта без VPS · 13 ноября 2026

## Завершённый локальный объём

Студия самостоятельно придумывает разные ситуации «А что, если…» без закрытого перечня тем. Выбор идеи, сценарий, правки и выпуск проходят согласование. Учебные истории о ЧС используют отдельную проверку памяток и источников.

Сервер готовит сцены, речь, субтитры, музыку, обложку и пакет с контрольными суммами. Lenovo выполняет финальную сборку MP4. На сервере финальный MP4 не рендерится.

Добавлены девять процедурных декораций, прозрачные слои персонажа, открывание рта по сигналу речи, моргание, движение и камера. Опционально доступны нейросетевые фоны Cloudflare с отдельным включением и лимитом. Это стилизованный 2D-риг; полноценная нейросетевая анимация тела и смена ракурсов не реализованы.

Субтитры сохраняют исходный текст. Необязательная серверная ASR-разметка использует faster-whisper; при её отсутствии временная разметка оценочная и не считается проверенной синхронизацией. Владелец просматривает и прослушивает ролик.

Проверяются целостность пакета, декодирование видео, формат, тишина и перегрузка сигнала, разрешение изображений, скорость чтения, эталоны персонажей. Автоматические исправления ограничены тремя; правка текста создаёт отдельную редакцию с повторным согласованием. Проверка сигнала не оценивает актёрское качество речи.

YouTube поддерживает точное согласование файла и метаданных, приватный доступ, доступ по ссылке, публичный выпуск и расписание. Ожидающий план можно отменить. При неоднозначном результате загрузки повтор блокируется до сверки.

TikTok поддерживает опциональную доставку в черновики через разрешённое приложение и OAuth video.upload. Автор завершает публикацию в TikTok. Автоматический Direct Post для личной утилиты не заявляется. Ручной экспорт MP4 остаётся доступен.

Очистка требует отдельного согласия на точный список, публичного обработанного видео YouTube, архивного сценария, отсутствия активного использования, резервной копии базы, эталонов и секретов. Во время разработки реальные файлы не удалялись. Черновик TikTok не является условием очистки.

Тренды: RSS, необязательный YouTube Data API, новые посты явно разрешённых Telegram-каналов, где добавлен бот. Скорость просмотров вычисляется только по повторным измерениям. Конкуренция не подменяется выдуманными числами. Аналитика объединяет реальные метрики серий и появляющихся персонажей без причинных выводов.

## Проверено здесь

- 104 теста Python; два длительных рендера выключены в обычном запуске.
- Новый послойный рендер отдельно прошёл реальную сборку и полное декодирование FFmpeg.
- Браузер: вход, восемь разделов, персонажи и эмоции, источники советов, генератор ситуаций, согласование/отмена плана YouTube, мобильная ширина.
- Проверки Python, JavaScript и Ruff. Сетевые интеграционные тесты используют подменённые ответы, без реальных отправок.

## Что требует доступов и среды

Docker отсутствует на этом компьютере: сборка Linux-образа и реальная работа eSpeak/Piper/ASR в контейнере не проверены. Нет VPS, DNS, Telegram и OAuth владельца; реальные облачные генерации, платформенные загрузки и получение аналитики не выполнялись.

Мастер запуска и инструкции подготовлены, однако первый серверный запуск может выявить совместимость образа, RAM или ограничение аккаунта. Естественный русский голос Piper нужно предоставить с проверенной лицензией; резерв eSpeak роботизированный. Опциональная модель ASR скачивается на сервер при первом использовании и требует свободной памяти.

Поэтому исходное широкое ТЗ не объявляется полностью подтверждённым одним локальным тестом. Необходим первый реальный цикл: идея → речь → рендер Lenovo → просмотр → согласованная отправка. До этого внешние функции являются реализованными, но не проверенными на аккаунтах владельца.
