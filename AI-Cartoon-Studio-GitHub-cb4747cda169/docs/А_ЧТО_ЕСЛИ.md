# «А что, если…» — разные сюжетные ситуации

Основной генератор больше не ограничен чрезвычайными ситуациями и не использует закрытый список тем. ИИ сам придумывает героя, необычное условие, цель, конфликт, завязку, жанр и правила мира. «Один мужчина остался на Земле» и «человек оказался на необитаемом острове» — примеры пользователя, а не обязательные шаблоны.

Допустимы фантастические миры, социальные допущения, приключения, выживание, загадки, драма и другие сочетания. Поле жанра свободное. Новые ситуации не требуют добавления категории в код или памятки по ЧС, поскольку это художественные истории, а не учебные инструкции по безопасности.

## Запуск

- В панели «Сериалы и серии» — блок **«А что, если… · любые сюжетные ситуации»**, кнопка **«Придумать новые сюжеты»**.
- В Telegram — `/ideas`.
- На сервере — ежедневное планирование при `STUDIO_STORY_AUTOPLAN=true` (по умолчанию включено).

За один запрос модель предлагает до трёх разных идей. Они приходят в Telegram и панель на выбор. Выбранный замысел передаётся сценаристу целиком. Каждая выбранная идея получает отдельную сюжетную память, чтобы правила одного мира не смешивались с другим. Правила и творческое задание сохраняются при правках и в рабочей памяти после одобрения серии.

Неизвестные показатели популярности остаются пустыми; идеи не выдаются за реальные новости. Дубли заголовков исключаются; при накоплении шести невыбранных сюжетов новые запросы приостанавливаются. Это ограничение расхода модели, а не количества возможных тем.

## Производство

Сценарий использует `format=what_if_story`, сохраняет обычные требования к длительности, персонажам, редакторской проверке и согласованию владельцем. Отдельного согласования источников ЧС для художественного сюжета нет. В видео встраивается маркировка вымысла. Герой действует по правилам мира: например, сценаристу запрещено без объяснения добавлять живых людей, если герой по условию один.

Учебный формат `emergency_story` сохранён отдельно со своими источниками и проверками. Общий ежедневный планировщик имеет приоритет, поэтому приложение не вызывает оба планировщика автоматически в один день. Для ежедневных учебных идей можно выключить STUDIO_STORY_AUTOPLAN и включить STUDIO_EMERGENCY_AUTOPLAN; вручную доступны оба режима.

Реальная генерация требует подключённой модели и серверной площадки. Пока они не подключены, задачи ожидают, а готовые сценарии не имитируют ответы ИИ. На Lenovo в рабочем режиме остаётся только финальный рендер.
